# std

Version 0.3.0, written in [Quoll 0.3.0](../language/package.md).

The dependency-free core library for packages written in Quoll; its root provides no interface or implementation of its own.

## Modules

```
  fs  native file-system [fs.path]s, whole-file reading and writing, and directory listing,
      inspection and recursive removal; its secret, how each target's standard library
      provides these operations
```
